# OSANEBI

## Real‑Time QA & Playtesting Platform

Osanebi is a platform built to support indie game studios during QA and playtesting sessions. It connects studios and playtesters, enabling real‑time experience reporting, structured feedback, and AI‑powered insights that help teams improve their games faster and more effectively.

## 🌟 What Osanebi Does
Enables live playtesting sessions between studios and testers

- Captures real‑time gameplay events, reactions, and feedback
- Generates AI‑structured reports to highlight issues, patterns, and improvement opportunities
- Helps studios prepare for pitching, publishing, and milestone reviews
- Converts feedback into actionable tasks with clear priorities
- Integrates directly into games through an Unreal Engine plugin

## 🛠️ Tech Stack

- Backend: ASP.NET Core (C#)
- Frontend: Razor Pages / Blazor / React (depending on final implementation)
- Database: SQL Server / PostgreSQL
- Game Integration: Unreal Engine plugin (C++/Blueprints)
- AI Layer: LLM‑powered summarization & analysis

## 📦 Unreal Engine Plugin
The Osanebi UE plugin allows any Unreal‑based game to:

- Send gameplay events to the Osanebi platform
- Capture tester feedback directly in‑game
- Trigger session markers (e.g., level start, boss fight, crash event)
- Sync logs and performance data

This plugin is included in the MVP and will be expanded as the platform grows.

## 🚧 Project Status
Osanebi is currently in MVP development, with the goal of securing funding or partnerships to:

- Expand plugin support to Unity, Godot, and other engines
- Enhance the AI feedback system
- Improve the studio dashboard and analytics suite

## 📈 Long‑Term Vision
Osanebi aims to become a complete ecosystem for indie studios:

- A hub for finding verified playtesters
- A tool for generating pitch‑ready reports
- A platform for tracking development progress
- A collaborative space for QA, design, and production teams
